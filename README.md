# User Creation App

A simple **User Management Web Application** built using **Node.js, Express.js, MongoDB, and EJS**.

This project demonstrates how to create a web application that accepts user information through forms and stores/manages the data using a backend server and database.

## 🚀 Features

* Create new users
* Store user information in MongoDB
* Display users using EJS templates
* Edit user information
* Delete users
* Server-side routing with Express.js
* Simple and responsive UI using CSS/Tailwind CSS

## 🛠️ Technologies Used

* **Node.js** – JavaScript runtime
* **Express.js** – Backend web framework
* **MongoDB** – Database
* **Mongoose** – MongoDB object modeling
* **EJS** – Template engine
* **HTML & CSS** – Frontend
* **Tailwind CSS** – UI styling

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Thejassuvarna/userCreation.git
```

### 2. Navigate to the project

```bash
cd userCreation
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
node app.js
```

Or, if you have a start script configured:

```bash
npm start
```

## 🌐 Usage

After starting the server, open your browser and visit:

```text
http://localhost:3000
```

You can then create and manage users through the application.

## 🎯 Purpose

This project was created to practice **backend development with Node.js and Express**, database operations with **MongoDB**, and server-side rendering using **EJS**.
